# AI 室內改造 SaaS 專案對齊文件

## 1. 原始需求

基於手機 AR / LiDAR 掃描、戶型圖轉 3D、AI 風格渲染等能力，規劃一個 SaaS 網站，讓使用者可以將家中空間或室內設計圖快速轉換為多種裝修風格方案，並以訂閱或點數制提供服務。

本階段僅進行專案規劃，不進入開發。

## 2. 當前專案現況

- 目前 repo 是 `Next.js 16 + React 19 + Tailwind CSS 4` 的單一前端專案。
- 現有產品定位為裝修引流頁，不是 SaaS 工具。
- 尚未具備會員系統、上傳流程、任務佇列、3D/AI 處理、支付、管理後台等核心能力。
- 尚未發現 `docs/` 與 `.docs/` 既有正式規劃文件；目前已開始在 `docs/ai-interior-saas/` 建立新需求文檔。

## 3. 產品重定位理解

新產品不再只是裝修公司落地頁，而是一個面向終端用戶與設計需求者的「AI 室內改造平台」。核心價值如下：

1. 低門檻：使用者可透過照片、戶型圖、掃描結果快速建立空間基礎模型。
2. 快速探索：同一空間可一鍵生成多種風格提案。
3. 視覺化比較：不同風格、家具與材質方案可直接預覽。
4. 可商業化：提供免費試用、付費渲染、專業方案與團隊版本。

## 4. 建議 MVP 範圍

### 4.1 目標使用者

- 一般屋主：想快速看裝修風格效果。
- 自裝族：重視尺寸、平面配置與預算前期探索。
- 室內設計師/小型工作室：需要快速出概念稿與風格提案。

### 4.2 MVP 功能

1. 首頁與產品介紹頁
2. 使用者註冊 / 登入
3. 新增專案
4. 上傳輸入素材
   - 房間照片
   - 戶型圖
   - 掃描輸出檔案或結構資料
5. 選擇空間類型與風格模板
6. 提交 AI 改造任務
7. 查看生成結果與版本比較
8. 點數或訂閱方案頁
9. 後台基礎營運面板

### 4.3 暫不納入 MVP

- 真正高精度原生 LiDAR 掃描能力
- 自建 3D 幾何重建引擎
- 可編輯級 3D CAD / BIM 工具
- 即時多人協作
- 原生行動 App
- 家具商城與供應鏈串接

## 5. 建議產品流程

1. 訪客進站
2. 註冊或登入
3. 建立空間專案
4. 選擇輸入方式
   - 上傳照片
   - 上傳戶型圖
   - 匯入外部掃描結果
5. AI 解析空間
6. 使用者選擇風格、房間類型、偏好條件
7. 送出生成任務
8. 系統產出 2D 效果圖 / 多版本提案
9. 使用者收藏、比較、下載或分享
10. 依方案消耗點數或升級付費方案

## 6. 技術方向初判

### 6.1 前端

- 維持使用現有 `Next.js` 作為 Web SaaS 前台。
- 後續可擴充 Dashboard、專案工作區、方案頁與管理後台。

### 6.2 後端

- 需新增正式後端能力，至少包含：
  - 身分驗證
  - 檔案上傳
  - 任務建立與狀態追蹤
  - 風格模板管理
  - 訂閱 / 點數 / 支付

### 6.3 AI 與外部整合

- 採「整合現成工具/API」優先，而非自建底層掃描技術。
- 手機掃描建議視為外部資料來源，例如：
  - RoomPlan / LiDAR 輸出
  - 第三方掃描 App 產生的平面圖或模型
- AI 風格改造初期可採影像生成/重繪工作流，而不是直接追求可編輯 3D 場景生成。

## 7. 商業模式建議

可優先評估以下兩種模式：

1. Freemium + 點數制
   - 免費帳號有限次試算或低解析度輸出
   - 進階渲染、高清下載、多版本比較需消耗點數
2. 訂閱制
   - 個人版：月費 + 每月固定額度
   - 專業版：更多專案數、品牌模板、團隊協作與 API 配額

## 8. 主要風險

1. 產品定位風險
   - 現有 repo 品牌與頁面內容偏向「裝修服務引流」，與新 SaaS 存在品牌與資訊架構衝突。
2. 技術落差風險
   - 從單頁網站升級到 SaaS，需要補齊大量基礎設施。
3. 成本風險
   - AI 影像生成、檔案儲存與背景任務都會持續產生成本。
4. 法規與版權風險
   - 上傳室內照片涉及隱私；若使用第三方模型與圖片生成，需確認授權與資料使用政策。

## 10. 待確認的高優先級問題

1. 這個新 SaaS 是否要直接取代現有 `Fit Renov` 引流網站定位，還是作為同 repo 的新產品線？
2. MVP 的核心輸入方式要優先做哪一種？
   - A. 單張/多張室內照片
   - B. 戶型圖/平面圖
   - C. 第三方掃描結果匯入
3. 首版輸出目標是什麼？
   - A. 2D 風格效果圖
   - B. 2D + 簡化 3D 白模預覽
   - C. 以 3D 為核心的可旋轉展示
4. 主要客群要先聚焦哪一類？
   - A. 一般屋主 B2C
   - B. 設計師 / 工作室 B2B
   - C. 雙邊皆支援，但先以 B2C 體驗為主
5. 收費策略要先以哪個方向規劃？
   - A. 免費體驗 + 點數包
   - B. 月訂閱制
   - C. 企業報價制
6. 是否接受第一版完全依賴第三方 AI / 掃描服務整合，而不自研底層模型？

## 10.1 已收斂決策摘要

- 產品定位：作為同 repo 的新產品線，不直接取代既有 `Fit Renov` 引流定位。
- MVP 輸入方式：優先支援 `照片上傳 + 戶型圖上傳`。
- 首版輸出：以 `2D AI 風格效果圖` 為核心。
- 商業模式：採 `免費體驗 + 點數制`。
- 技術策略：第一版接受以第三方 AI / 掃描服務整合為主，不自研底層模型。
